After A to B session switching and a successful B response with zero attempts, A's saved answer remained in B's input. This exposes a prior account's private answer within a reused browser session and risks submitting the wrong draft. Server ownership filtering remains intact. No remote IDOR was demonstrated.

The real-component browser regression fails on unmodified PR #122 with `actual: PRIVATE_A_ANSWER`, `expected: ''`. The fix adds `components/contests/contest-account-boundary.tsx` and wraps room/admin workspaces in a fresh, account-keyed SWR provider. `tests/contest-session-harness.tsx` and `tests/contest-session.browser.mjs` exercise real components, SWR and the Better Auth client with synthetic responses. Twelve checks cover saved answers, same-account draft preservation, delayed prior-account reads, sign-out at 1440/375 px, admin draft clearing, session failure/retry and dashboard invalidation. These fixtures do not qualify real login/providers.
